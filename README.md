# budgester.github.io

Source for **https://budgester.com** (GitHub Pages, classic Jekyll build from `master`, theme Cayman).

- `index.md`: home page. `blog.md`: post list. `_posts/`: posts (three moved from the old Blogger site, keeping their original URLs).
- `docs/brownfield-devops.md` is an unpublished draft, and `IDEAS.md` is a list of ideas for future posts (both excluded in `_config.yml`).
- DNS for budgester.com is in [budgester/aws](https://github.com/budgester/aws) (`route53.tf`).

Changes go on a branch with a pull request, like the AWS repo.
